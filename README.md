# GraviTrack — Redesigned v3

This version keeps the existing GraviTrack functionality and adds a CSS 3D animated campus hero to the Browse page.

## Run
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm start`.
4. Open `http://localhost:4000`.

## 3D interaction
- Buildings, pins, route line, glow and drone animate continuously.
- Move the mouse over the 3D campus to tilt it with pointer parallax.
- The design automatically respects `prefers-reduced-motion`.
